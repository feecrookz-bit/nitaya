# 10. Glossary

| Term | Meaning |
|---|---|
| **Range** | One product as the store lists it: a stone or tile in one size and thickness. 36 on the store, 41 product pages on the site |
| **Pack** | The unit the yard sells natural stone in: a crate of slabs. Mixed packs hold four sizes; single-size packs one |
| **Pallet** | The delivery unit for porcelain and tiles. On the site "pack" and "pallet" are the same quantity; the word follows the category |
| **Box** | The sales unit for indoor tiles and cladding; the pallet is only the delivery quantity |
| **Cover** | m² per pack, pallet or box, computed from the packing |
| **Split** | Selling part of a pack: loose slabs. Every pack splits except boxes and cladding |
| **Loose slabs** | Slabs sold outside a whole pack; for mixed packs, a set in the pack's four sizes |
| **Mixed patio pack** | 22 mm sandstone: 16 × 900 × 600, 16 × 600 × 600, 16 × 600 × 290, 12 × 290 × 290 = 18.19 m² |
| **Allowance for cuts** | The extra ordered for cutting and breakage, 5/10/15/20%, a tick box, never silently added |
| **Essentials** | The warehouse's jointing compounds (Joint-Tec, Por-Tec), primer, step treads, edging, granite setts and cobbles |
| **Ask for a price** | An Essentials line put in the bag as a quote because the yard has not given a price |
| **Edition, family, season** | Ways the home page arranges the same products; nothing is sold differently |
| **Studio render** | A slab on a neutral ground made from the yard's photograph; the `p-` files |
| **Texture** | The square crop of a render used by the 3D views; the `t-` files |
| **Scene** | A project photograph of laid stone; the `scene-` files |
| **Gate** | The password page in front of the preview; the site is encrypted behind it |
| **Single-file build** | The one-HTML-file build used by the audits and the pack screenshots |
| **Hash route** | An address of the form `/#/page/id`; the site has no server-side pages |
| **Path shim** | The script that turns `/product/x` into `/#/product/x` |
| **Redirects file** | `_redirects`: the signposts from every old store address to the new site |
| **The sheet** | "stock tracker main", the Google Sheet and Apps Script that is the warehouse's stock system; its "Database Products" tab is the authority on pack sizes |
| **Store API** | WooCommerce's browser-safe API for products, cart and checkout, needing no key |
| **The pack** | The owner presentation pack (PDF), separate from a pack of stone |
| **Fee, Coleisha, Simar** | Fee built the site and does DNS and the connections; Coleisha takes over the site; Simar maintains the sheet |
